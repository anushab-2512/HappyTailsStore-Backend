# 🐾 HappyTailsStore – Full-Stack E-commerce Web Application

HappyTailsStore is a full-stack e-commerce web application for pet products, developed using React.js, Spring Boot, Java, and MySQL. The application provides a seamless shopping experience with secure authentication, product browsing, shopping cart management, online payments, and order management.

## 📌 Project Overview

HappyTailsStore enables users to:

- Register and securely log in using JWT Authentication
- Browse products by category
- Search and view product details
- Add and manage items in the shopping cart
- Place orders using the Razorpay Payment Gateway
- View order history
- Reset passwords using OTP verification
